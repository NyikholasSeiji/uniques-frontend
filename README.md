# UniqueS Front-end

Front-end da plataforma **UniqueS**, desenvolvido por **Nyikholas Seiji**.

O **UniqueS (US)** é uma plataforma web de skincare personalizado, oferecendo uma interface moderna para recomendação de produtos com base em um questionário sobre a pele.

---

## Tecnologias

* React
* Vite
* TypeScript
* Tailwind CSS
* React Router DOM
* Axios

---

## Requisitos

* Node.js 18+
* npm
* Back-end em execução

---

## Instalação

```bash
git clone <url-do-repositorio>
cd uniques-frontend
npm install
```

---

## Configuração

Crie um arquivo `.env`:

```env
VITE_API_URL=http://localhost:8080/api
```

---

## Executando

```bash
npm run dev
```

Build de produção:

```bash
npm run build
```

---

## Funcionalidades

* Cadastro e login
* Autenticação JWT
* Rotas protegidas
* Gerenciamento de perfil
* Consumo de API REST
* Questionário de skincare *(em desenvolvimento)*
